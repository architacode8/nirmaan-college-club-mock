# ⚡ NST-SDC Web Platform | Newton School of Technology

Official web platform for the **Software Development Club (NST-SDC)** at **Newton School of Technology, Pune**.  
Built with **Pure HTML5 and CSS3** (zero external JavaScript frameworks or heavy runtime dependencies), prioritizing clean semantic architecture, accessible web standards, and instant load performance.

---

## 🌟 Live Features & Highlights

- **Pure HTML5 & Modern CSS3**: Zero bloat, instant Time-To-Interactive (TTI), and 100% accessible layout structure.
- **Cyberpunk Dark Obsidian Theme**: Engineered with high-contrast tokens (`#06080C`, `#0D121D`, and `#00F0FF` electric cyan accents).
- **Responsive 16:9 YouTube Container**: Pure CSS `aspect-ratio: 16 / 9` widescreen video embed that adapts fluidly across all devices.
- **Core Leadership Roster**: Real club directory with dedicated member cards and direct LinkedIn profiles.
- **Open-Source Repositories Showcase**: Live links to 6 active NST-SDC student projects and developer tools.
- **Live Campus Platforms**: Direct access to the deployed **Nirmaan Portal** and **Scratch Leaderboard**.
- **Accessible Registration Portal**: Native HTML5 regex validation (`pattern="[0-9]{8,10}"`) for student roll numbers and Discord onboarding.

## 🚀 Getting Started Locally

No complex build steps, package managers, or bundlers required!

1. **Clone the repository:**
   ```bash
   git clone https://github.com/architacode8/nirmaan-college-club-mock.git
   cd nirmaan-college-club-mock
   ```

2. **Open in browser:**
   - Double click `index.html` or open it directly in any modern browser.
   - Alternatively, use VS Code / IDE **Live Server** extension:
     ```bash
     npx serve .
     ```
