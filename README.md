# NST-SDC Web Platform

A lightweight, responsive web platform built for the **Software Development Club (NST-SDC)** at **Newton School of Technology, Pune**.

---

## 🛠️ Tech Stack & Concepts

- **HTML5**: Semantic landmark tags (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<form>`).
- **CSS3**:
  - CSS Custom Properties (`:root` variables) for centralized theme tokens.
  - **Flexbox**: 1-dimensional alignment for navigation and hero actions.
  - **CSS Grid**: Responsive card layouts using `repeat(auto-fit, minmax(...))`.
  - **Responsive Video**: Pure CSS `aspect-ratio: 16 / 9` container without JavaScript.
- **Form Validation**: Native HTML5 form validation using `required` and `pattern="[0-9]{8,10}"`.
- **Zero Frameworks**: Pure HTML & CSS with zero external libraries or bundle dependencies.
